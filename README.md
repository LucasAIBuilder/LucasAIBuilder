# Lucas Machado

I build software with coding agents, mostly AI systems that automate operations work for small businesses and the agent infrastructure I run every day. I also build small tools I use myself. I design everything, direct the agents, and test and review the results.

Engineer by training (Rutgers, B.S. Electrical & Computer Engineering; Carnegie Mellon, Master's in Entertainment Technology). Producer at Zynga, then twelve years running a remote marketing and sales business I co-founded. Since September 2025 I run [Causelayer](https://causelayer.co), designing and delivering AI systems for small businesses. Based in the Algarve, Portugal.
